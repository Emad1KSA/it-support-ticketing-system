# 🛠️ IT Support & Helpdesk Ticketing System

A web-based IT Support Ticketing System built using PHP & MySQL to log, track, and manage technical support requests.

## 🚀 Live Demo
You can test the live working project here:
👉 **[Click Here to Try the Live Application](http://it-support.kesug.com/)**

## 💻 Tech Stack
- *Frontend:* HTML5, CSS3, JavaScript
- *Backend:* PHP
- *Database:* MySQL

## 🛠️ Features
- Submit technical support tickets.
- Save requests directly into the MySQL database.
- Clean and responsive user interface for mobile and desktop.

## ⚙️ How to Run Locally
1. Clone or download this repository.
2. Move the project folder to your htdocs directory (XAMPP/WAMP).
3. Create a MySQL database and configure the database connection.
4. Open http://localhost/it-support/index.php in your browser.
